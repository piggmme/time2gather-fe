# 랜딩 문구 다국어 반영 및 배포

작업일: 2026-10-26 (KST).

## 변경

한국어에서 합의한 상단·메인·설명의 역할과 의미를 지원하는 22개 언어에 반영했다. 기존 15개 언어는 `src/marketing/copy.ts`, 추가 7개 언어는 `src/marketing/locales/*.json`을 수정했다. 버튼과 다른 영역의 문구는 이번 변경 대상이 아니다.

- 상단: 여럿이 만날 땐, 타임투게더
- 메인: 우리 모두 되는 시간
- 설명: 가능한 시간을 모아, 모두가 만날 시간을 찾아보세요.

지속적인 작업 기준은 [다국어 작업 지침](i18n-guidelines.md)에 정리하고 `AGENTS.md`와 README에 연결했다.

## 검증

- 번역 검사: 22개 언어, 앱 문구 464개, 보간 변수와 마케팅 리소스 확인 통과.
- 다국어 회귀 검사: 언어 협상·저장된 선택·날짜/시간·복수형·RTL 관련 형식·시간대·폰트 검사 통과.
- 변경한 TypeScript의 ESLint 및 프로덕션 빌드 통과.
- 로컬, Cloud Run 후보 URL, 운영 도메인 각각에서 실제 브라우저로 22개 언어의 HTTP 200, HTML 언어, 상단·메인·설명 세 문구의 정확한 일치를 확인했다. 한국어는 저장된 다른 언어의 영향을 배제하도록 `/?lang=ko`를 사용했다.
- 각 환경에서 한국어·영어·독일어·아랍어·우르두어·텔루구어의 320px·390px·1440px, 총 18개 조합에서 페이지와 세 문구의 가로 넘침이 없음을 확인했다. 한국어·독일어·아랍어의 320px 스크린샷을 시각 검토했다.
- 세 환경의 검사에서 브라우저 런타임 오류가 없었다. 번역의 원어민 검수는 수행하지 않았다.
