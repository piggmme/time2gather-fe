# 초대 코드 입력 사용량

홈에서는 약속 만들기만 표시합니다. 초대 코드 입력은 상단 메뉴에서 제공하며, 햄버거 메뉴의 문의는 마지막에 둡니다. 소개는 푸터에서 엽니다.

| 이벤트 | 전송 기준 |
| --- | --- |
| `meeting_code_submitted` | 코드 입력 화면에서 비어 있지 않은 코드나 링크로 검색 버튼을 누름 |
| `meeting_code_opened` | 해당 검색으로 서버 조회에 성공한 약속 화면을 엶 |
| `meeting_code_response_saved` | 해당 약속에서 주최자 외 참여자가 일정 응답과 필요한 장소 응답 저장을 모두 완료함 |

같은 탭에서 검색한 뒤 30분 이내의 행동을 연결합니다. 새 검색은 별도 시도로 셉니다. 입장 성공과 투표 완료는 검색 시도마다 한 번만 세며, 새로고침과 같은 응답의 재저장으로 늘어나지 않습니다. 모두 불가 응답도 저장 성공에 포함합니다. 주최자 응답, 존재하지 않는 코드, 저장 실패와 일반 초대 링크로 바로 연 약속은 코드 입력의 참여 완료로 세지 않습니다.

`input_kind`는 직접 코드 입력인 `code`와 입력 화면에 링크를 붙여 넣은 `link`를 구분합니다. 종류별 보고서는 GA4 이벤트 범위 맞춤 측정기준으로 `input_kind`를 등록한 뒤 확인합니다. 이번 변경에서는 GA4 관리자 설정을 변경하지 않습니다.

코드는 연결을 위해 같은 탭의 메모리와 `sessionStorage`에 보관하며 분석 서버로 보내지 않습니다. 30분이 지나면 귀속 대상에서 제외하고 다음 조회 때 표시를 지웁니다. 저장소를 사용할 수 없으면 같은 페이지 이동 흐름에서만 연결합니다. 제목, 닉네임, 코드와 링크 원문은 이벤트에 넣지 않습니다. 기존 운영 호스트 제한, 자동 검사 제외와 수집 끄기 설정을 동일하게 적용합니다.

배포 이후 이벤트 수와 `입장 성공 / 제출`, `참여 완료 / 입장 성공`을 함께 봅니다. 제출 횟수는 사람 수가 아니며 광고 차단 등으로 수집이 누락될 수 있습니다. 사용 빈도와 실제 참여 결과를 확인한 뒤 기능 유지 여부를 판단합니다.
