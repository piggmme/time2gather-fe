# 관리자 로그인 및 목록 사용성 배포

작업일: 2026-10-26 (KST).

## 변경

- 관리자 설정 API와 Google SDK를 동시에 로드하고, 대시보드 코드는 로그인 후에 로드한다.
- JavaScript 실행 전에도 번역된 로그인 안내가 HTML에 표시된다. Google 연결을 미리 준비하고 API/SDK에 15초 제한과 재시도를 적용했다.
- 약속 링크는 새 탭에서 열어 원래 관리자 탭의 인증·검색·페이지 위치를 보존한다. 같은 탭에서 이동한 뒤 뒤로가기로 인증을 복원하거나 새로고침 후 인증을 유지하는 변경은 아니다.
- 섹션 바로가기, 전체 및 목록별 새로고침, 조회 중 페이지 이동 비활성화를 추가했다.
- 전체 약속 대비 확정률을 표시한다. 두 신규 번역 키를 지원 언어 22개에 반영했다.

## 검증

- 프로덕션 빌드, TypeScript, 변경 코드 ESLint, 번역 키 검사, 다국어 회귀 검사 통과.
- Google SDK 동시 로드 공유, 기존 SDK 재사용, 시간 초과·네트워크 실패·잘못된 SDK 응답 후 재시도 검사 통과.
- Cloud Run 후보: `/admin`, `/admin/login`의 22개 언어 총 44개 응답에서 HTTP 200, HTML 언어, 로그인 제목·설명·상태, 신규 번역, no-store/noindex 확인.
- 운영 `time2gather.org`, `www.time2gather.org`: 같은 조건으로 총 88개 응답 확인. 두 도메인의 관리자 JS/CSS가 검증한 로컬 빌드와 바이트 단위로 일치한다.
- 운영 두 도메인에서 로그인 설정 활성, 인증 없는 세션·통계·사용자·약속 API 401, 홈·약속 생성 페이지 HTTP 200 확인.
- 운영 브라우저에서 실제 Google 로그인 버튼 렌더링을 확인했다. IAB에서 버튼 클릭 후 인증 완료로 진행되지 않아 로그인 이후 대시보드 및 상세 탭 복귀의 실제 인증 세션 검증은 완료하지 못했다.
- 웹/모바일 지연 차이의 원인을 운영 기기별 시간 측정으로 확정한 것은 아니다. 전체 언어의 대시보드 시각 검수와 원어민 번역 검수는 수행하지 않았다.

## 후속 검토

최근 7일·30일 약속 생성 수, 투표 참여율, 확정까지 걸린 시간을 다음 지표로 검토한다. DAU·재방문율은 방문 이벤트 수집이 필요하다. 현재 Firestore 목록 구현은 전체 문서를 읽고 메모리에서 페이지를 나누므로, 지표 확대 전에 조회·집계 구조 개선이 우선이다. DB의 ADMIN 역할 수는 실제 Google 로그인 허용 목록 수와 다르므로 관리자 인원 지표로 표시하지 않았다.
