# 일정·장소 투표의 참여자 표시

구현일: 2026-10-26. 아래 내용은 로컬 구현·검증 기준이며 운영 배포는 별도다.

## 시간 달력

- 결과 달력의 실제 시간 칸에 마우스를 올리면 날짜·시간·표시 시간대와 해당 참여자의 이름·프로필을 보여준다. 200ms 지연으로 스쳐 지나가는 칸마다 미리보기가 뜨지 않게 한다.
- 키보드 포커스로도 확인할 수 있고 Escape로 닫는다. 미리보기 위로 마우스를 옮겨 목록을 읽을 수 있다.
- 클릭하면 기존 참여자 상세창이 열린다. 터치 화면은 기존 탭 상세창을 사용하며 호버 미리보기를 띄우지 않는다.
- `mode='edit'`인 시간 선택 화면은 참여자 미리보기에서 제외한다. 드래그·클릭·터치 선택 동작을 유지한다.
- 실제 빈 시간 칸은 기존 다국어 '참여자 없음' 문구를 표시한다. 시간대 변환으로 생긴 날짜·시간 격자의 빈 자리처럼 해당 슬롯 데이터 자체가 없는 경우에는 미리보기를 만들지 않는다.
- 참석자 수에서 이름을 추정하거나 재조회하지 않는다. 시간대가 변환된 결과 달력의 `schedule[date][time].participants`를 사용하므로 클릭 상세창과 같은 참석자를 보여준다.
- 포털로 렌더링해 달력 스크롤 영역에 잘리지 않게 하고, 칸 위아래 배치 및 화면 너비·높이 제한으로 좁은 화면에서도 읽을 수 있게 한다.

관련 코드: `src/components/daily/DailyParticipantsTooltip.tsx`, `DailyCell.tsx`, `DailyGrid.tsx`, `Daily.tsx`.

## 장소 투표

- 결과 요약, 장소 결과 탭, 장소 선택 화면에 공통 `LocationVoters`를 사용한다.
- 각 장소 아래 '이 장소에 투표한 사람'과 이름·프로필 목록을 항상 표시한다. 프로필 이미지만 보고 사용자를 추측할 필요가 없다.
- 0표인 장소는 명시적인 빈 상태를 표시한다. 긴 이름과 혼합 문자 이름은 줄바꿈하고 방향을 격리한다.
- 서버에서 제공한 각 장소의 `voters`를 그대로 사용한다. 장소 선택 중 아직 저장하지 않은 체크 상태를 확정된 투표자 목록에 섞지 않는다. 투표 수나 저장 API를 변경하지 않는다.
- 장소 체크박스의 접근성 이름은 장소명으로 지정해, 투표자 이름이 늘어나도 선택 대상이 명확하게 유지되도록 한다.
- 새 문구 두 개는 지원하는 22개 언어에 모두 추가했다.

관련 코드: `src/components/LocationVoters/`, `src/components/ResultPage/ResultContent.tsx`, `src/components/SelectPage/LocationVoteSection.tsx`.

## 검증

실제 컴포넌트에 로컬 테스트 데이터를 넣고 브라우저에서 다음을 확인했다. 운영 데이터 생성·수정은 하지 않았다.

- 시간 칸별 정확한 참여자 및 빈 상태, 호버 영역 유지, 포커스, Escape, 기존 클릭 상세창.
- 시간 선택 화면의 미리보기 제외와 선택 동작, 모바일 터치 상세창.
- 장소 결과·선택 화면의 투표자 이름, 0표 상태, 장소 체크박스 동작.
- 320px·390px의 긴 이름 줄바꿈, 한국어·아랍어·우르두어 320px에서 미리보기 화면 안 배치.
- 번역 검사·시간대/다국어 회귀 검사·타입 검사·관련 ESLint·프로덕션 빌드.
